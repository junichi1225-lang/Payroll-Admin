# RDRA Analysis Plugin

RDRA（リレーションシップ駆動要件分析）の考え方で要求分析を対話的に進め、結果を HTML でプレビューするプラグイン。

## 含まれるスキル

- **rdra-analysis** — 「要求分析したい」「業務を整理したい」「RDRA で書きたい」などで起動。アクター・外部システム、領域、業務一覧、状態モデル、利用シーンを対話で洗い出す

## 使い方

インストール後、「要求分析したい」と話しかけるとスキルが起動します。対話を通じて `rdra/analysis.md` に分析内容が蓄積され、HTML プレビューで確認できます。

## セットアップ

追加の環境変数や外部サービスは不要です。Node.js がインストールされていれば HTML プレビューの生成・開発サーバーが利用できます。
